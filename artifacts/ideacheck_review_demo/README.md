# IdeaCheck: MessMind + QueueSense demo

- `../IdeaCheck-MessMind-QueueSense-demo.mp4` — 1920×1080 demo with a locally generated, male British English neural narration.
- `captions.srt` — captions retimed to the new narration.
- `narration.txt` — spoken script.
- `review-summary.md` — review inputs, findings, and source.
- `audio/` — scene narration WAV files.

The voiceover uses Kokoro-82M (`bm_george`), an open-weights voice model. It is an original narrator voice and does not imitate a specific person. The MessMind prompt and QueueSense repository README were reviewed with IdeaCheck's local, rules-based first-pass engine. The QueueSense example reviews the README only; it does not audit source code or run the application.
